# Provenance and distribution boundaries

This repository contains original continuation tooling under GPL-3.0-only.
LasVola/godhand-recomp is a separately fetched dependency, pinned in upstream.json;
its declared GPL license and its own attribution/notices remain applicable.
That project builds on PS2Recomp and other projects described by its notices.
Do not relabel their work as ours or as MIT. No decompiled/translated game source
is included here. Source exposure in the separate evaluation is recorded; this
continuation is not presented as an independent clean-room engine.

God Hand and its contents belong to their respective rights holders. No game
rights or affiliation are asserted. A repository license is not permission to
redistribute game assets, program images, generated game code or saves. No such
material may be added to this repository, its releases, Actions artifacts or CI.

The old independent MIT lab remains separate and paused, not completed.
Selected earlier original reports/entries retain their MIT notice in
docs/IMPORTED_MIT_LICENSE.txt and exact source provenance in docs/migration.json.
The new static generator/publication workflow is original GPL continuation code.
Only explicitly selected already-reviewed rendered screenshots are republished
unchanged; game imagery is neither MIT nor GPL, nor rights-holder-authorized by
our repository license. No extracted asset sheets or game data are migrated.

The original native resource bridge calls the privately fetched upstream generic
SHA-256 helper; that implementation is not vendored here. Integration metadata
selects exact normalized host-source hashes and records only original additions,
not game functions or instruction patches. Its byte offsets index open-source
host files, not the game disc. The prior private range helper was original GPL
evaluation code; the public bridge retains that provenance and is not MIT.

The public prototype host main/window templates are original GPL continuation
source, informed by the separate prototype evaluation. Numeric/profile values
remain private qualification inputs. Three host override recipes contain our
reviewed edits against separately fetched GPL upstream1646d885, not vendored
files or game bodies. Source postimage equality is not an independent clean-room,
ABI or rights-holder authorization claim. Generated observed game functions are
excluded; even a parameterized translated game body would remain prohibited.

The public host-profile selector policy was authored with prior qualified roles,
the private parameter table and original prototype instructions consulted privately.
Its hash/operand extraction metadata and original algorithms contain no game
instruction words, address map or translated body. No independent clean-room,
semantic/ABI or fresh-native-base claim follows. Historical captured modules and
populated profile outputs remain private and retain separate game rights.

The original observer-insertion policy publishes only our declarations/calls and
hash/line/EOL metadata. Raw and instrumented game bodies remain private; even
byte-identical reconstructed outputs may not be distributed here. The native
project emitter is original CMake glue, not vendored runtime/game source or an
ABI/read-only certification. Prior source exposure/qualification remains explicit.
