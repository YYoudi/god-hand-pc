Public native pack bridge — 6 November 2026

Decision

Continue the tested LasVola PC base through the separate original GPL tooling god-hand-pc, upstream-first, not another Rust rewrite and not an automatic upstream mirror. Preserve the MIT lab unchanged. LucasPicoli remains a comprehension/matching reference, not a demonstrated PC port. Its provisioned Linux compiler smoke tests and sample object passed; the interrupted full ELF/map remain zero-byte outputs, so no matching rebuild is claimed. See the evaluation and prototype result.

What was actually reproduced

The fresh personal-disc build was preserved before relinking. The public installer checks exact pinned host-file preimages, creates a private derived source revision and builds the original bridge. It edits five host/build integration paths and adds four original bridge files, not generated game functions or guest instructions. All nine changed paths and the binary are checked before launch; unrelated source/binary identity failures refuse execution.

Resource to rendering

The pack names st1/r100.dat, outer SCP ordinal 3, bank 0, image 0. The original metadata planner resolves ISO9660 → FST/AFS → DAT/SCP → TM3/TIM3, checks the retail profile and accepts only the supported same-size stored bytes. No absolute disc offset belongs in a user pack. The launcher freezes the original validated payload per run; the native bridge checks its exact size/digest and applies overlaps to read buffers. The normal guest resource loader and renderer then consume those bytes. CD-image, positively identified raw-ISO IOP host-stream and EE sector-fallback paths are covered; the actual enabled run logs application through the EE sector reader. No rendered-image repainting is involved.

The original test file contains uniform magenta indexed pixels and an authored palette: 8,256 bytes, SHA-256 fe467079e9695b5832af4b79a383db7ae76bc704ab439c2e481ceb65a543c357. The public make_example_pack.py generates those exact bytes without reading a game asset. This is a diagnostic, not remaster art or an extracted texture.

Reproduction boundary

Use the separate GPL repository's setup and runtime contract:

python pc.py setup --iso "G:\path\God Hand (USA).iso" --vsroot "G:\your-msvc-root"
python pc.py install-packs --workspace-name retail-setup
python make_example_pack.py --output .local/example-pack
python pc.py run --workspace-name retail-setup --iso "G:\path\God Hand (USA).iso" --pack .local/example-pack/pack.json

Run without --pack for original assets. Installer/source/binary/ISO checks are not silently ignored when a pack is invalid. Native read failures leave original read-buffer bytes unchanged; strict mode concerns prelaunch pack validation. An installed derived workspace is not a pristine setup workspace: use a new name for another fresh build. Do not overwrite old failed attempts or original discs.

Remaining roadmap, in order

  • Persistence and usability: owner-led manual controller/audio checks and a

genuine in-game save then load in a new process. Use a legitimate owner save or a focused inter-area state; do not make development depend on beating levels.

  • Broader resource validation: another named resource/scene with restoration

controls before expanding the accepted storage-format subset or pack count.

  • HD asset path: specify a decoded original-texture import and size-aware

upload boundary; prove larger dimensions with an invented asset and same-view controls. Same-size byte replacement does not prove HD support.

  • Rendering/stability: collect targeted original/reference pairs and bounded

regression states, retain defects; resolve diagnostics rather than guessing NOPs or successful returns. No full-playthrough, performance or hardware-fidelity claim.

  • Prototype: separately investigate the reproduced unsupported kernel syscall

0x7a against licensed primary SDK/runtime ABI with synthetic tests. The linked native prototype has no observed title/frame/debug menu. Do not reuse retail function maps or claim the reported debug shortcut already works.

Generation still reports one unresolved error. Physical controls, audible audio, real game Save/Load, HD resizing, hot reload, later stages and complete fidelity remain open. Stored workspace cards and runtime snapshots are not a verified in-game save round trip. The paused independent-engine rendering objective is not achieved by this separate native continuation.
