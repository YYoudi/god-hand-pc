Development notes

This project continues LasVola’s God Hand PC base. It is not a new Rust engine or a mirror of generated game code.

A supported personal USA retail ISO is required. No game, extracted assets or executable is distributed. A local opening/first-fight build and a same-size external texture test have been reproduced; a complete accurate port and remaster are not yet validated.

ISO-required setup · Work ahead · Reviewed original comparisons

Known limits and next checks
  • Genuine in-game Save → process exit → Load is unverified. The owner no longer has a personal save; runtime snapshots and downloaded saves are not substitutes.
  • Physical keyboard/controller usability, audible audio, later stages and complete campaign fidelity remain open. No autonomous level-beating is planned.
  • Public named packs still cover one same-size stored resource. A separate private 512x512 GPU proof now works on that128x128 source without changing guest bytes, but public HD installation, unique file identity/aliases, other resources/scenes and a general remaster remain unverified.
  • Retained generation errors/warnings remain visible. A bounded C++ reachability result is not full guest coverage or an implemented unknown instruction.
  • The separate prototype links but startup blocks on kernel syscall 0x7a; no working debug menu.
  • Widescreen, simulation-safe FPS changes, modern lighting and multiplayer each require separate evidence.
  • Controls pause remains experimental and opt-in. Legacy v1 has a reproduced forced admitted-audio-callback race; separately selected audio-v2 excludes it. A private diagnostic also preserves one ordinary nonempty queue at an earlier retail point; PCM content, audible/device, focus, peripheral and full-machine/campaign gates remain open. Original remains unchanged.

Next: Make the proven private larger-texture boundary reproducible as a checked opt-in variant/pack workflow, preserving Original/v1/audio-v2 and keeping game-derived references private. Broader hardware/focus/audio, true game saving and human campaign validation remain separate gates.
